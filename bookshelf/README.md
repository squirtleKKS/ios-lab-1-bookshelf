# Bookshelf App

## Как запустить

1. Открыть проект в Xcode.  
2. Выбрать симулятор.  
3. Нажать Run (⌘R).

---

## Поддерживаемые сценарии

1. **Добавление книги**  
   Кнопка `+` - ввод данных - сохранение.

2. **Удаление книги**  
   Свайп влево по строке или через режим редактирования.

3. **Фильтрация**  
   Фильтр по названию, автору, жанру, тегу и году.

4. **Сброс фильтров**  
   Кнопка «Все».

5. **Обработка ошибок**  
   Ошибки отображаются через Alert.
